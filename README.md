# TradeLog Ver.7

Ver.6に「編集」「検索」「絞り込み」を追加しました。

## Ver.7の追加機能
- 取引の編集
- 売却済み取引の売却情報も編集可能
- 銘柄名 / 買った理由 / 売った理由 / 反省から検索
- 保有中 / 売却済みで絞り込み
- 理由カテゴリーで絞り込み
- 自信度で絞り込み
- 絞り込み解除
- 削除時に確認ダイアログ

## 既存機能
- ダッシュボード
- 累計損益グラフ
- カテゴリー別グラフ
- 投資のクセ分析
- CSVバックアップ / 復元
