# TradeLog Ver.8

公開サイト向けに「初めて来た人でも分かるUI」を追加したバージョンです。

## Ver.8の追加
- ヒーローエリア
- TradeLogの価値を一文で説明
- 「まず1件記録する」CTA
- 「使い方を見る」導線
- 3ステップの使い方説明
- 架空データによる分析サンプル表示
- 空データ時の案内改善
- 投資助言ではなく振り返りツールである旨を表示
- スマホ向けレイアウト調整

## 既存機能
- 取引記録
- 売却結果登録
- 編集
- 検索 / 絞り込み
- 勝率 / 損益 / 平均利益率
- グラフ
- 投資のクセ分析
- CSVバックアップ / 復元
